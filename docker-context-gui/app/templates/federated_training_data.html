Federated Learning -- Training Data

Expected folder structure

This data stays on this server -- it's read directly by the local training container each round and is never uploaded to any other instance. Only the resulting model weights (not encrypted) and per-case data statistics leave this host.

your-folder/ images/ case001.nii.gz case002.nii.gz labels/ case001.nii.gz case002.nii.gz

Every file in images/ needs a matching file in labels/ with the exact same filename. .nii / .nii.gz only. Drag the whole your-folder in below (or its images/+labels/ contents directly) -- either way works, matching is done by filename, not by folder depth.

Everything you upload in one go becomes one batch, shown as its own group below (who uploaded it, when, how many cases) with a single button to delete the whole batch later. Individual cases can still be deleted one at a time too.

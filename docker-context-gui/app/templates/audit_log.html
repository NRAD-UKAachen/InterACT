This page merges two sources. This app's own records — iRODS, the PACS search, the batch API — are appended to {{ log_dir }}/phi-access-<date>.jsonl. OHIF's traffic to dcm4chee never reaches this app and is recorded by nginx in {{ nginx_log }}; rows from there are marked nginx in the CSV export's source column. Opening one study is hundreds of image requests, so repeated views of the same study by the same person within {{ collapse_minutes }} minutes are shown as a single row with a request count — the underlying file keeps every individual request. Times are shown in server local time; both logs store UTC, which is what the CSV's ts column carries (ts_local has the converted value). Neither log is ever rewritten from the web app. {% if retention_days %} Files older than {{ retention_days }} days are removed automatically. {% else %} No automatic deletion is configured — set AUDIT_RETENTION_DAYS to enable it. {% endif %} See Documentation/GUI.md, "PHI access audit trail".

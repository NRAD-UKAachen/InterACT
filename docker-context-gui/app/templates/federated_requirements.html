How To

1 Connect sites

On Instances, with each partner:

  • Swap base URLs (Copy Base URL). It must be reachable from the partner's network -- use an IP if unsure.
  • Add Remote Instance, send them the token it shows, and paste the token they send back. The card turns Connected.
  • Each site clicks Allow for the model under Training Permissions. Without it, that site can't be selected.

2 Upload training data at each site

On Training Data, upload matching images/ + labels/ NIfTI files. Data never leaves the site -- only model weights do.

Before starting, all sites must agree on (nothing checks this for you):

  • Labels -- the same number means the same structure everywhere (e.g. 1 = tumor).
  • Images -- the same modality (CT or MRI, chosen when starting), and the same channels in the same order.

3 Start the federation

On Training Rounds → Start New Federation: pick the sites, rounds and epochs. Tick Also train on this site's own local training data to include your own data.

  • Round 0 analyzes every site's data and builds one shared training setup (resolution, crop size, etc.) automatically.
  • When the run finishes, download the results zip (model, recipe and inference script) from the run's row.

4 Use the finished model

The downloaded zip contains everything needed to run the model on its own, outside this GUI:

  • final_model.pt -- the trained weights.
  • recipe.tar.gz -- the training setup that the model expects inputs to be preprocessed with.
  • inference_script.py -- a standalone script that applies the recipe and runs inference.
  • requirements.txt -- pinned package versions matching the environment the model was trained under.

After unzipping, it is recommended to set up a python environment and run it:

pip install -r requirements.txt

python inference_script.py \
    --recipe recipe.tar.gz \
    --checkpoint final_model.pt \
    --input /path/to/case.nii.gz \
    --output-dir ./predictions

--input can also be a folder of *.nii.gz files. Each result is written as <output-dir>/<case>_seg.nii.gz, an integer label map resampled back to the input's original geometry -- what each label number means isn't stored in the model or recipe, so confirm that with whoever ran the training job.

5 Follow training (optional)

Each training site writes a log to airflow/data/workflows/fl-segresnet/<run_id>/local/round_<n>/local-output/segresnet_ckpt/training.log. loss should go down; acc is the Dice score per class (0-1, higher is better).
